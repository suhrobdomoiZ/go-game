# Текстовая игра

## Описание
>**Задание на курсе от VK Education:** создать прототип текстовой игры.

## Цель:
- знакомство с синтаксисом Go на практике
- работа с состоянием(``struct Player``)
- создание первого проекта на Go

## Запуск прогаммы

1. Клонируйте репозиторий:
```bash
git clone https://github.com/suhrobdomoiZ/go-game.git
```
2. В корневой папке проекта в командной строке пропишите:
```bash
go build -o game.exe
.\game.exe  
```
